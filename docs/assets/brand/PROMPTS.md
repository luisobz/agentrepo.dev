# Ilustraciones estáticas

Herramienta: `imagegen` integrada. Referencia: lámina de cinco poses suministrada por el propietario. Los banners se copiaron directamente y los SVG se reconstruyeron como vectores; no usan generación de imágenes.

## Extracción

```text
Extract the FIVE existing static mascot illustrations from this reference as a clean alpha-transparent PNG asset sheet. Faithfully preserve this exact rounded robot appearance, expressions, poses, laptop and clipboard; do NOT redesign or pixelate. Arrange five equal square cells in one horizontal row: waving hero, idle, happy, working, helping. Uniform character height, centered baseline, generous transparent padding. Remove all words (Guide avatar, Hero Sprite, Idle, Happy, Working, Helping), background and ground shadows. Preserve garnet/cream/pink character details. This is for STATIC branding illustrations only, not animation. No new text or decorations. Transparent alpha required.
```

## Revisión de bordes

Clean up the alpha edges of this STATIC illustration asset sheet. Keep all five existing characters/poses, sizes, colors, geometry, faces, equipment and positions unchanged. Remove the scattered red/magenta fringe pixels and tiny disconnected edge artifacts around the characters so each silhouette has a smooth clean antialiased edge on true transparent alpha, suitable for both white and dark backgrounds. Remove no intentional pink emotion lines, stars or character details. No redesign, no extra shadows, no background, no text. Preserve all five fully visible illustrations.
