# Primeras fichas de agentes

Guías editoriales aportadas por el propietario el 11 de octubre de 2026,
revisadas documentalmente en origen el 10 de octubre. No se instalaron ni
se ejecutaron estos proyectos durante esta importación. Se conservan sus
limitaciones, notas de versión y ejemplos propuestos.

`entries.json` contiene los metadatos y enlaces etiquetados para cada ficha.
Los README y homepages de los tres repositorios se cotejaron el 11 de octubre.
Las cuentas personales, organizaciones, comunidades y referencias del ecosistema
se identifican expresamente; no se atribuye a Gentle Shell una web exclusiva
ni se presenta el X del creador de NanoClaw como cuenta corporativa.

La versión 1.0.0 corresponde a la ficha editorial de AgentRepo, no a la versión
instalada de upstream. Los archivos descargables son guías, no el código del
proyecto. La comparativa se conserva como material de referencia, sin publicar
un artículo adicional en el blog.

La carga debe usar la API de administración, leyendo primero si el slug ya existe.
No sobrescribir fichas existentes ni ejecutar los comandos incluidos en las guías.
